# CCC r24: 仕訳CSV取込

既存の直接入力・財務数値入力を維持し、③仕訳CSVモードを追加。

## 利用方法
1. `index.html` を開き「③ 仕訳CSVから計算」を選択。
2. CSVを選択。UTF-8（BOM有無対応）またはShift_JISを指定。
3. 対象期間、月末平均／期首期末2点平均を選択。
4. 科目対応を確認し、5区分それぞれに確認チェック。候補分類は確定判断ではない。
5. 売上債権・棚卸資産・仕入債務の**開始日の直前残高**を入力。空欄は未確認、0は確認済みゼロ。
6. 税処理と対象期間の完全性を確認。欠けている項目は「未算出」と表示。
7. 根拠付きCSV出力または印刷/PDF保存。

## 対応CSV
「月日」、借方/貸方それぞれの「科目コード」「科目名」「取引金額」「税抜き金額」が必須。年月日は西暦。CSVは20MB以下。引用符、カンマ、改行を含むセル対応。片側空欄の複合仕訳も各借方・貸方を個別集計。数値空欄はゼロ変換しない。

## 会計上の範囲
- 損益＝税抜き金額、B/S残高＝取引金額による帳簿残高。債権債務が税込の場合は基準差が残ることを明示。
- 売上・原価の借貸差引を集計。月次棚卸の戻入と計上をネット処理。
- 在庫開始残高の自動推測なし。期首残高は手入力。
- 5xxxは製造原価も含む候補。試算表への照合を必須にする。
- 月末平均は対象各月末の単純平均（期首を含まない）。端数月は2点平均を使用。
- 対象期間を初日・最終仕訳日より延長する場合、CSV抽出範囲内である明示確認が必要。無仕訳月を欠落と区別して確認する。
- 決算の損益締切仕訳を含むデータは対象外。売上0以下・原価0以下・負の月末/終了残高は該当指標を算出しない。
- 現行BAST業種平均（365日基準）との比較は平均方法・税込税抜等の差に注意。
- 限界利益率・金利は仕訳だけで決まらないため、③では資金負担インパクトは自動算出しない。

## プライバシー
外部解析スクリプト（Google Analytics）と外部ポータルJavaScriptを除去し、静的リンクへ置換。CSVはメモリ内処理のみ。localStorage/IndexedDB等に保存しない。CSPの `connect-src 'none'` で送信を禁止。読み直し失敗・新ファイル・消去で以前の結果を破棄。科目変更で確認と開始残高を破棄。

## 検証
- `node --test tests/engine.test.js`
- `node tests/browser.test.js`（Playwright、Chromiumが利用可能な環境）。CLIで起動したローカルサーバーのみを利用。実顧客CSVはテスト資材・リポジトリに含めない。
- デプロイ不要の簡易確認：`python3 -m http.server 8765` をこのディレクトリで起動し、`http://localhost:8765/`を開く。

## 公開
現行GitHub Pagesリポジトリに `index.html`, `csv-engine.js`, `csv-ui.js` を同じ階層で反映。既存画像はそのまま必要。純静的でビルド・サーバー・APIキー不要。
この改修作業ではpush/デプロイは未実施。原本・個人データは本リポジトリの外に保持。

追加のDOM回帰検証：`node tests/dom.test.js`（開発用jsdomが必要）。これは実ブラウザの描画・ネットワーク検証の代用ではありません。
